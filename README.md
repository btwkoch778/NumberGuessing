# Təsadüfi Ədəd Tapma Oyunu

## Layihə haqqında

Bu layihə C# proqramlaşdırma dili və Windows Forms texnologiyası vasitəsilə hazırlanmış sadə masaüstü tətbiqidir. Proqram istifadəçiyə kompüter tərəfindən təsadüfi seçilmiş ədədi tapmaq imkanı verir.

## Proqramın xüsusiyyətləri

- Kompüter 0–100 aralığında təsadüfi ədəd seçir.
- İstifadəçi öz təxminini daxil edərək ədədi tapmağa çalışır.
- Proqram daxil edilən ədədin gizli ədəddən böyük və ya kiçik olduğunu bildirir.
- Hər düzgün və yanlış təxmin cəhd sayı kimi hesablanır.
- Boş xana və etibarsız giriş zamanı `ErrorProvider` vasitəsilə xəbərdarlıq göstərilir.
- Ədəd tapıldıqda oyun başa çatır və nəticə göstərilir.
- Yeni oyun başladıldıqda əvvəlki nəticələr sıfırlanır.

## İstifadə olunan texnologiyalar

- C#
- Windows Forms
- .NET
- Visual Studio

## Proqramdan istifadə qaydası

1. Proqramı başladın.
2. **Yeni oyun** düyməsinə basın.
3. Axtarılan ədəd xanasına 0–100 arasında tam ədəd daxil edin.
4. **Yoxla** düyməsinə basın.
5. Ekrandakı göstərişlərə əsasən növbəti təxmininizi edin.
6. Düzgün ədədi tapdıqda oyun başa çatacaq.
7. Yenidən oynamaq üçün **Yeni oyun** düyməsinə basın.

## Məqsəd

Bu layihənin məqsədi C# proqramlaşdırma dilində təsadüfi ədədlərlə işləməyi, şərt operatorlarını, hadisələrin idarə edilməsini, istifadəçi interfeysini və xəta yoxlamasını tətbiq etməkdir.

# Random Number Guessing Game

## About the Project

This project is a simple desktop application developed using the C# programming language and Windows Forms. It allows users to guess a randomly generated number.

## Features

- The computer generates a random number between 0 and 100.
- The user enters a guess to find the hidden number.
- The application indicates whether the guess is higher or lower than the hidden number.
- Each valid guess, whether correct or incorrect, counts as an attempt.
- The `ErrorProvider` displays a warning when the input is empty or invalid.
- The game ends when the correct number is guessed, and the result is displayed.
- Starting a new game resets the previous results.

## Technologies Used

- C#
- Windows Forms
- .NET
- Visual Studio

## How to Use

1. Run the application.
2. Click the **Yeni oyun (New Game)** button.
3. Enter an integer between 0 and 100 in the input field.
4. Click the **Yoxla (Check)** button.
5. Follow the on-screen hints to make your next guess.
6. The game ends when you guess the correct number.
7. Click **Yeni oyun (New Game)** to play again.

## Purpose

The purpose of this project is to practise working with random numbers, conditional statements, event handling, graphical user interfaces, and input validation in C#.
